# PROJECT_CONTEXT — UKCUT

- **Client** : Barbershop Chez UKCUT (propriétaire : UKCUT, @ukcut1), 832 rue Saint-Joseph Est, Québec (Saint-Roch).
- **Statut** : démo de prospection construite par Stéphane (Djassa Digital) le 16 nov. 2026. Le client n'a encore rien validé.
- **Objectif** : un site vitrine haut de gamme qui envoie vers la réservation Fresha. Réservation et paiement intégrés prévus en phase 2.
- **Cible** : hommes et familles de Québec, clientèle du centre-ville, touristes (service « nouveau client »).
- **Pages** : Accueil, Services, Équipe, Galerie, Contact, 404.
- **Stack** : Astro 7 (statique), CSS maison, polices auto-hébergées (Fontsource), images optimisées en WebP. Déploiement Vercel.
- **Sources des données** : fiche Fresha du salon (adresse, horaires, services, prix, équipe, note 4,9 / 936 avis) et profil Instagram @ukcut1, relevés le 16 nov. 2026.
