# UKCUT — site du Barbershop Chez UKCUT (Québec)

Site vitrine en Astro. Démo de prospection, pas encore validée par le client.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # sortie dans dist/
```

- Contenu (adresse, horaires, services, équipe, liens) : `src/data/site.ts`
- Styles et tokens : `src/styles/global.css`
- Photos : `src/assets/img/`
- Mémoire du projet et direction artistique : `docs/`
